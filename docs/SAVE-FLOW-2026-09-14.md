# Save confirmations and automatic next prediction

Released to https://scorerush-sigma.vercel.app on 14 September 2026.
Production deployment: `dpl_3AohH8cAbjR84M556Bv73HKGgq7B` (READY), URL `scorerush-27jkmdzrg-world-cup-friends.vercel.app`.

## Behavior

- Saving a prediction from a match detail page now opens the next missing, editable prediction in the same tournament, stage and round. Ordering is kickoff then match ID. It skips explicit saved picks, closed/cancelled/postponed matches, and wraps to earlier missing games when needed. Automatic defaults remain missing. Retrospective entries are eligible only while the existing onboarding rules permit them.
- After the last eligible prediction, the user returns to the match list with a completion confirmation. If the save succeeds but the next-game lookup fails, the saved state remains confirmed, with a link to continue manually; the app does not incorrectly claim completion or a failed save.
- The detailed form uses the existing authenticated HTTP write endpoint with a bounded request, a duplicate-submit guard and confirmed score checking. Navigation and draft clearing occur only after an acknowledged successful write. Failed/uncertain requests retain input and do not advance. The server and RLS continue to enforce write authorization and lock times.
- A shared top toast survives client navigation, is dismissible, supports screen readers and expires after six seconds. Detail saves, quick saves (including the welcome guide's first pick) and bonus saves announce success only after acknowledgment. Bonus confirmations name the category; failure feedback remains distinct. Mixed Hebrew/Latin score labels use directional isolation.
- No database migration, paid service, new dependency, real-user prediction submission or notification activation was required.
